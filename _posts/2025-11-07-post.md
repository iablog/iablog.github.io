Você já tentou pedir algo para uma IA e a resposta não foi exatamente como esperava ou até mesmo incorreta? Muitas vezes, a solução está em **mostrar exemplos** do que você quer, ao invés de apenas explicar. **In-Context Learning** é a capacidade de LLMs de se adaptarem a uma tarefa com base no contexto fornecido. Dentro dessa diretriz existe a técnica **Few-Shot Learning** (aprendizado com poucos exemplos), que é uma das ferramentas mais poderosas da Engenharia de Prompts.

## O que é Few-Shot Learning?

Few-Shot Learning é uma técnica na qual você fornece ao modelo de IA alguns exemplos de entrada e saída desejados antes de fazer sua pergunta real. É como mostrar a um assistente alguns modelos do que você quer antes de pedir que ele faça algo novo. Existe o **Few-Shot** com vários exemplos e **One-Shot** com apenas um exemplo.

## Por que usar exemplos?

Modelos de linguagem são excelentes em reconhecer padrões. Quando você mostra exemplos, está ajudando o modelo a entender o formato de resposta que você espera, o estilo de linguagem adequado, o nível de detalhes esperado e padrões específicos que você deseja seguir.

## Exemplo Prático 1: Classificação de Sentimentos 

Vamos ver como evoluir um prompt progressivamente aplicando as técnicas de engenharia de prompts.

### Versão Inicial

```
Classifique o sentimento desta mensagem:
"O produto chegou rápido, mas veio com defeito."
```

**Problema:** Resposta muito verbosa e inconsistente.
**Resposta possível:** "A mensagem expressa sentimentos mistos. O cliente está satisfeito com a velocidade da entrega, mas insatisfeito com a qualidade do produto..."

---

### Versão 2: Aplicando Clareza

```
Você é um classificador de sentimentos de feedback de clientes.

Tarefa: Classifique o sentimento da mensagem em uma das categorias:
- Positivo: Cliente satisfeito
- Negativo: Cliente insatisfeito  
- Neutro: Sem opinião clara ou misto

Mensagem: "O produto chegou rápido, mas veio com defeito."

Responda apenas com a categoria (Positivo, Negativo ou Neutro).
```

**Melhoria:** Resposta mais direta, mas ainda pode variar.
**Resposta:** "Negativo"

---

### Versão 3: Aplicando Few-Shot

```
Você é um classificador de sentimentos de feedback de clientes.

Tarefa: Classifique o sentimento da mensagem em uma das categorias:
- Positivo: Cliente satisfeito
- Negativo: Cliente insatisfeito  
- Neutro: Sem opinião clara ou misto

Exemplos:

Mensagem: "Adorei o produto! Superou minhas expectativas."
Sentimento: Positivo

Mensagem: "Não funcionou como esperado. Muito decepcionado."
Sentimento: Negativo

Mensagem: "O produto é ok. Nada de especial."
Sentimento: Neutro

Agora classifique:
Mensagem: "O produto chegou rápido, mas veio com defeito."
Sentimento:
```

**Melhoria:** Resposta consistente com o formato dos exemplos.
**Resposta:** "Negativo"

---

### Versão 4: Adicionando Formato Estruturado (JSON)

```
Você é um classificador de sentimentos de feedback de clientes.

Tarefa: Classifique o sentimento da mensagem em uma das categorias:
- Positivo: Cliente satisfeito
- Negativo: Cliente insatisfeito  
- Neutro: Sem opinião clara ou misto

Exemplos:

Mensagem: "Adorei o produto! Superou minhas expectativas."
Output: {"sentimento": "Positivo", "confianca": 0.95}

Mensagem: "Não funcionou como esperado. Muito decepcionado."
Output: {"sentimento": "Negativo", "confianca": 0.90}

Mensagem: "O produto é ok. Nada de especial."
Output: {"sentimento": "Neutro", "confianca": 0.85}

Agora classifique:
Mensagem: "O produto chegou rápido, mas veio com defeito."

Retorne APENAS um objeto JSON válido no formato dos exemplos.
```

**Melhoria:** Resposta estruturada, fácil de processar programaticamente.
**Resposta:** `{"sentimento": "Negativo", "confianca": 0.88}`

## Exemplo Prático 2: Extração de Informações

Vamos extrair dados de currículos para alimentar um banco de dados.

### Versão Inicial

```
Extraia informações deste currículo:
"Ana Costa atua como gerente de projetos desde 2018, com especialização em metodologias ágeis."
```

**Problema:** Formato imprevisível, campos variáveis.

---

### Versão 2: Aplicando Clareza

```
Extraia as seguintes informações do currículo:
- Nome completo
- Profissão/cargo
- Anos de experiência (calcular se necessário)

Currículo: "Ana Costa atua como gerente de projetos desde 2018, com especialização em metodologias ágeis."
```

**Melhoria:** Campos específicos, mas formato ainda livre.

---

### Versão 3: Aplicando Few-Shot

```
Extraia as informações dos currículos no formato: Nome | Profissão | Anos de Experiência

Exemplos:

Currículo: "Maria Silva trabalha como engenheira de software há 5 anos, tendo atuado em diversas empresas de tecnologia."
Extração: Maria Silva | Engenheira de Software | 5

Currículo: "João Santos é designer gráfico com 8 anos de experiência no mercado criativo."
Extração: João Santos | Designer Gráfico | 8

Agora extraia:
Currículo: "Ana Costa atua como gerente de projetos desde 2018, com especialização em metodologias ágeis."
Extração:
```

**Melhoria:** Formato consistente e previsível.
**Resposta:** "Ana Costa | Gerente de Projetos | 7"

---

### Versão 4: Adicionando Formato Estruturado (JSON)

```
Extraia informações dos currículos no formato JSON estruturado.

Exemplos:

Currículo: "Maria Silva trabalha como engenheira de software há 5 anos, tendo atuado em diversas empresas de tecnologia."
Output:
{
  "nome": "Maria Silva",
  "profissao": "Engenheira de Software",
  "anos_experiencia": 5,
  "especializacoes": ["tecnologia"]
}

Currículo: "João Santos é designer gráfico com 8 anos de experiência no mercado criativo."
Output:
{
  "nome": "João Santos",
  "profissao": "Designer Gráfico",
  "anos_experiencia": 8,
  "especializacoes": ["mercado criativo"]
}

Agora extraia:
Currículo: "Ana Costa atua como gerente de projetos desde 2018, com especialização em metodologias ágeis."

Retorne APENAS o objeto JSON.
```

**Resposta:**
```json
{
  "nome": "Ana Costa",
  "profissao": "Gerente de Projetos",
  "anos_experiencia": 7,
  "especializacoes": ["metodologias ágeis"]
}
```

## Exemplo Prático 3: Conversão de Formatos 

### Versão Inicial

```
Converta para ficha técnica:
"Mouse sem fio ergonômico com 6 botões programáveis e sensor óptico de 4000 DPI."
```

---

### Versão 2: Aplicando Clareza

```
Você é um especialista em catalogação de produtos de tecnologia.

Tarefa: Converta a descrição do produto em uma ficha técnica estruturada contendo:
- Categoria do produto
- Principais características técnicas
- Diferenciais

Descrição: "Mouse sem fio ergonômico com 6 botões programáveis e sensor óptico de 4000 DPI."
```

---

### Versão 3: Aplicando Few-Shot

```
Você é um especialista em catalogação de produtos de tecnologia.

Converta as descrições de produtos para o formato de ficha técnica:

Exemplo 1:
Produto: "Notebook leve e potente, ideal para trabalho remoto. Possui processador Intel i7, 16GB de RAM e SSD de 512GB."

- Categoria: Notebook
- Processador: Intel i7
- Memória RAM: 16GB
- Armazenamento: SSD 512GB
- Uso Recomendado: Trabalho remoto

Exemplo 2:
Produto: "Smartphone com câmera de 48MP, bateria de longa duração e tela AMOLED de 6.5 polegadas."

Agora converta:
Produto: "Mouse sem fio ergonômico com 6 botões programáveis e sensor óptico de 4000 DPI."
Ficha Técnica:
```

```
- Categoria: Mouse
- Tipo: Sem fio
- Botões: 6 programáveis
- Sensor: Óptico 4000 DPI
- Característica: Ergonômico
```

## Como usar Few-Shot 

### 1. Escolha exemplos representativos
Seus exemplos devem cobrir diferentes casos que você espera encontrar.

**Ruim (todos os exemplos são similares):**
```
Classifique como spam ou não-spam:

Email 1: "Ganhe dinheiro rápido!" → Spam
Email 2: "Compre agora com desconto!" → Spam
Email 3: "Promoção imperdível!" → Spam
```

**Bom (exemplos diversos):**
```
Classifique como spam ou não-spam:

Email 1: "Ganhe dinheiro rápido clicando aqui!" → Spam
Email 2: "Reunião marcada para amanhã às 14h" → Não-spam
Email 3: "Seu pedido foi enviado. Código: XYZ123" → Não-spam
```

### 2. Seja consistente no formato
Mantenha o mesmo formato em todos os exemplos.

```
Corrija os erros de português:

Texto: "Os menino foi na praia"
Correção: "Os meninos foram à praia"

Texto: "Ela estar muito feliz"
Correção: "Ela está muito feliz"

Texto: "Nós vai viajar amanhã"
Correção:
```

### 3. Use delimitadores claros
Separe claramente os exemplos da pergunta real.

```
Traduza os provérbios do português para o inglês:

[EXEMPLO 1]
PT: "Quem não tem cão, caça com gato"
EN: "Necessity is the mother of invention"

[EXEMPLO 2]
PT: "Águas passadas não movem moinhos"
EN: "Let bygones be bygones"

---
[NOVA TRADUÇÃO]
PT: "De grão em grão, a galinha enche o papo"
EN:
```

### 4. Quantidade adequada de exemplos

*0 (Zero-Shot)*: Tarefas muito simples
*1 (One-Shot)*: Tarefa simples com formato específico
*2-3 (Few-Shot): Ideal para maioria dos casos*
*4-5*: Tarefas complexas ou muitas variações
*5+*: Raramente necessário

## Exemplo Avançado: Análise de Sentimentos Contextualizados

Vamos ver um caso complexo onde Few-Shot com contexto faz grande diferença:

### Versão Completa (Todas as técnicas combinadas)

```
Você é um analisador de sentimentos especializado em detectar ironia e sarcasmo.

Tarefa: Analise o sentimento REAL da frase considerando o contexto, identificando se há ironia ou sarcasmo.

Categorias:
- Positivo (genuíno): Elogio sincero
- Negativo (direto): Crítica explícita
- Negativo (irônico/sarcástico): Elogio aparente que é na verdade crítica

Exemplos:

Frase: "Que maravilha, mais um aumento de preço!"
Contexto: Cliente reclamando de reajuste
Análise:
{
  "sentimento_aparente": "Positivo",
  "sentimento_real": "Negativo",
  "tipo": "irônico",
  "justificativa": "Uso de 'maravilha' em contexto negativo indica ironia"
}

Frase: "Adorei a experiência, recomendo para todos"
Contexto: Avaliação positiva de produto
Análise:
{
  "sentimento_aparente": "Positivo",
  "sentimento_real": "Positivo",
  "tipo": "genuíno",
  "justificativa": "Elogio sincero com recomendação explícita"
}

Frase: "Nossa, que serviço impecável"
Contexto: Cliente esperou 3 horas no atendimento
Análise:
{
  "sentimento_aparente": "Positivo",
  "sentimento_real": "Negativo",
  "tipo": "sarcástico",
  "justificativa": "Elogio exagerado em contexto de insatisfação clara"
}

Agora analise:
Frase: "Excelente, chegou uma semana depois do prometido"
Contexto: Entrega atrasada de produto importante

Retorne APENAS o objeto JSON no formato dos exemplos.
```

**Resposta:**
```json
{
  "sentimento_aparente": "Positivo",
  "sentimento_real": "Negativo",
  "tipo": "sarcástico",
  "justificativa": "Uso de 'excelente' para descrever atraso indica sarcasmo"
}
```

## Combinando Todas as Técnicas: 

Aqui está a fórmula para criar prompts de alta qualidade:

```
[1. PERSONA]
Você é um [especialista/assistente] em [domínio específico].

[2. TAREFA CLARA]
Tarefa: [Descrição específica e detalhada da tarefa]

[3. CATEGORIAS/ESTRUTURA]
[Liste as categorias, formatos ou estruturas esperadas]

[4. CRITÉRIOS]
Considere:
- [Critério 1]
- [Critério 2]
- [Critério 3]

[5. EXEMPLOS (FEW-SHOT)]
Exemplos:

[EXEMPLO 1]
Input: [entrada]
Output: [saída estruturada]

[EXEMPLO 2]
Input: [entrada]
Output: [saída estruturada]

[EXEMPLO 3]
Input: [entrada]
Output: [saída estruturada]

---
[6. INPUT REAL]
Agora processe:
Input: {seu_input_aqui}

[7. FORMATO DE SAÍDA]
Retorne APENAS [formato específico: JSON/XML/tabela/etc].
Não inclua texto adicional.
```

## Quando Usar Few-Shot?

### Use Few-Shot quando:
- A tarefa tem um **formato específico** de saída
- Você precisa de **consistência** nas respostas
- O modelo está **interpretando mal** suas instruções
- Há **nuances** difíceis de explicar (ironia, contexto cultural, etc.)
- Você quer **respostas estruturadas** (JSON, XML, tabelas)
- A tarefa envolve **padrões** que são mais fáceis mostrar que explicar

### Evite Few-Shot quando:
- A tarefa é muito **simples** e autoexplicativa
- Você tem **limitações severas de tokens**
- Cada caso é **completamente único** sem padrões
- A resposta deve ser **criativa/original** (storytelling, brainstorming)

## Conclusão

Few-Shot Learning é uma técnica poderosa que transforma a forma como interagimos com modelos de IA. Ao combinar **clareza nas instruções**, **exemplos representativos** e **formatos estruturados**, você cria prompts que produzem resultados consistentes e de alta qualidade. Na próxima vez que não estiver satisfeito com a resposta de uma IA, tente aplicar essas técnicas progressivamente. Você pode se surpreender com a melhora na qualidade!

**Experimente você mesmo:** Pegue uma tarefa que você frequentemente faz com IA e aplique as técnicas progressivamente:
1. Escreva o prompt básico
2. Adicione clareza e detalhes
3. Inclua 2-3 exemplos
4. Estruture a saída em JSON

Compare os resultados em cada etapa e veja a evolução!
