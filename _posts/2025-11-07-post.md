Você já tentou pedir algo para uma IA e a resposta não foi exatamente como esperava ou até mesmo incorreta? Muitas vezes, a solução está em **mostrar exemplos** do que você quer, ao invés de apenas explicar. **In-Context Learning** é a capacidade de LLMs de se adaptarem a uma tarefa com base no contexto fornecido. Dentro dessa diretriz existe a técnica **Few-Shot Learning** (aprendizado com poucos exemplos), que é uma das ferramentas mais poderosas da Engenharia de Prompts.

## O que é Few-Shot Learning?

Few-Shot Learning é uma técnica na qual você fornece ao modelo de IA alguns exemplos de entrada e saída desejados antes de fazer sua pergunta real. É como mostrar a um assistente alguns modelos do que você quer antes de pedir que ele faça algo novo. Existe o **Few-Shot** com vários exemplos e **One-Shot** com apenas um exemplo.

## Por que usar exemplos?

Modelos de linguagem são excelentes em reconhecer padrões. Quando você mostra exemplos, está ajudando o modelo a entender o formato de resposta que você espera, o estilo de linguagem adequado, o nível de detalhes esperado e padrões específicos que você deseja seguir.

## Exemplo Prático: Conversão de Formatos 

### Versão Inicial

```
Converta para ficha técnica:
"Mouse sem fio ergonômico com 6 botões programáveis e sensor óptico de 4000 DPI."
```
**Problema** Resposta muito verbosa e inconsistente.
**Resposta**
```
## Ficha Técnica - Mouse Sem Fio Ergonômico

**Produto:** Mouse Sem Fio Ergonômico

**Características Principais:**

*   **Tipo:** Sem Fio
*   **Design:** Ergonômico
*   **Número de Botões:** 6
*   **Programabilidade:** Sim (6 botões programáveis)
*   **Sensor:** Óptico
*   **DPI:** 4000

**Especificações Técnicas:**

*   **Conexão:** Bluetooth ou Receptor USB (Especificar qual)
*   **Distância de Transmissão:** (Especificar a distância, ex: até 10 metros)
*   **Tecnologia do Sensor:** (Especificar o tipo, ex: Óptico de alta precisão)
*   **Taxa de Polling:** (Especificar a taxa, ex: 125Hz)
*   **Bateria:** (Especificar tipo e duração, ex: Pilha AA, até 20 horas de uso)
*   **Dimensões:** (Especificar altura, largura e profundidade)
*   **Peso:** (Especificar o peso)
*   **Material:** (Especificar o material, ex: Plástico ABS)
*   **Compatibilidade:** (Especificar sistemas operacionais, ex: Windows, macOS, Linux)

**Recursos Adicionais:**

*   (Adicionar recursos como: Scroll rápido, clique lateral, ajuste de peso, etc.)

**Acessórios Inclusos:**

*   (Listar os acessórios inclusos, ex: Pilhas, Manual do Usuário)

**Observações:**

*   (Adicionar informações relevantes, como garantia, certificações, etc.)

**Importante:** Preencha os campos em branco com as informações específicas do produto para completar a ficha técnica.
```


### Versão 3: Aplicando Few-Shot

```
Você é um especialista em catalogação de produtos de tecnologia.

Converta as descrições de produtos para o formato de ficha técnica:

Exemplo 1:
Produto: "Notebook leve e potente, ideal para trabalho remoto. Possui processador Intel i7, 16GB de RAM e SSD de 512GB."
Ficha Técnica:
- Categoria: Notebook
- Processador: Intel i7
- Memória RAM: 16GB
- Armazenamento: SSD 512GB
- Uso Recomendado: Trabalho remoto

Exemplo 2:
Produto: "Smartphone com câmera de 48MP, bateria de longa duração e tela AMOLED de 6.5 polegadas."
Ficha Técnica:
- Categoria: Smartphone
- Câmera: 48MP
- Tela: AMOLED 6.5"
- Destaque: Bateria de longa duração

Agora converta:
Produto: "Mouse sem fio ergonômico com 6 botões programáveis e sensor óptico de 4000 DPI."
Ficha Técnica:
```
**Melhoria** Resposta consistente com o formato dos exemplos.
**Resposta:**

```
- Categoria: Mouse
- Tipo: Sem fio
- Ergonomia: Sim
- Botões: 6 programáveis
- Sensor: Óptico 4000 DPI
```

### Versão 4: Adicionando Formato Estruturado (JSON)

```
Você é um especialista em catalogação de produtos de tecnologia.

Converta descrições de produtos para ficha técnica em JSON.

Exemplo 1:
Produto: "Notebook leve e potente, ideal para trabalho remoto. Possui processador Intel i7, 16GB de RAM e SSD de 512GB."
Output:
{
  "categoria": "Notebook",
  "especificacoes": {
    "processador": "Intel i7",
    "ram": "16GB",
    "armazenamento": "SSD 512GB"
  },
  "uso_recomendado": "Trabalho remoto"
}

Exemplo 2:
Produto: "Smartphone com câmera de 48MP, bateria de longa duração e tela AMOLED de 6.5 polegadas."
Output:
{
  "categoria": "Smartphone",
  "especificacoes": {
    "camera": "48MP",
    "tela": "AMOLED 6.5\"",
    "bateria": "Longa duração"
  },
  "uso_recomendado": null
}

Agora converta:
Produto: "Mouse sem fio ergonômico com 6 botões programáveis e sensor óptico de 4000 DPI."

Retorne APENAS o objeto JSON.
```
**Melhoria:** Resposta estruturada, fácil de processar programaticamente.
**Resposta:**
```json
{
  "categoria": "Mouse",
  "especificacoes": {
    "tipo": "Sem fio",
    "ergonomico": true,
    "botões": "6 programáveis",
    "sensor": "Óptico 4000 DPI"
  },
  "uso_recomendado": null
}
```

## Exemplo Avançado: Análise de Sentimentos Contextualizados

Vamos ver um caso complexo onde Few-Shot com contexto faz grande diferença:

### Versão Completa (Todas as técnicas combinadas)

```
Você é um analisador de sentimentos especializado em detectar ironia e sarcasmo.

Tarefa: Analise o sentimento REAL da frase considerando o contexto, identificando se há ironia ou sarcasmo.

Categorias:
- Positivo (genuíno): Elogio sincero
- Negativo (direto): Crítica explícita
- Negativo (irônico/sarcástico): Elogio aparente que é na verdade crítica

Exemplos:

Frase: "Que maravilha, mais um aumento de preço!"
Contexto: Cliente reclamando de reajuste
Análise:
{
  "sentimento_aparente": "Positivo",
  "sentimento_real": "Negativo",
  "tipo": "irônico",
  "justificativa": "Uso de 'maravilha' em contexto negativo indica ironia"
}

Frase: "Adorei a experiência, recomendo para todos"
Contexto: Avaliação positiva de produto
Análise:
{
  "sentimento_aparente": "Positivo",
  "sentimento_real": "Positivo",
  "tipo": "genuíno",
  "justificativa": "Elogio sincero com recomendação explícita"
}

Frase: "Nossa, que serviço impecável"
Contexto: Cliente esperou 3 horas no atendimento
Análise:
{
  "sentimento_aparente": "Positivo",
  "sentimento_real": "Negativo",
  "tipo": "sarcástico",
  "justificativa": "Elogio exagerado em contexto de insatisfação clara"
}

Agora analise:
Frase: "Excelente, chegou uma semana depois do prometido"
Contexto: Entrega atrasada de produto importante

Retorne APENAS o objeto JSON no formato dos exemplos.
```

**Resposta:**
```json
{
  "sentimento_aparente": "Positivo",
  "sentimento_real": "Negativo",
  "tipo": "irônico",
  "justificativa": "O uso de 'Excelente' em relação a um atraso de entrega é uma forma de ironia."
}
```

## Combinando Todas as Técnicas: 

Aqui está a fórmula para criar prompts de alta qualidade:

```
[1. PERSONA]
Você é um [especialista/assistente] em [domínio específico].

[2. TAREFA CLARA]
Tarefa: [Descrição específica e detalhada da tarefa]

[3. CATEGORIAS/ESTRUTURA]
[Liste as categorias, formatos ou estruturas esperadas]

[4. CRITÉRIOS]
Considere:
- [Critério 1]
- [Critério 2]
- [Critério 3]

[5. EXEMPLOS (FEW-SHOT)]
Exemplos:

[EXEMPLO 1]
Input: [entrada]
Output: [saída estruturada]

[EXEMPLO 2]
Input: [entrada]
Output: [saída estruturada]

[EXEMPLO 3]
Input: [entrada]
Output: [saída estruturada]

---
[6. INPUT REAL]
Agora processe:
Input: {seu_input_aqui}

[7. FORMATO DE SAÍDA]
Retorne APENAS [formato específico: JSON/XML/tabela/etc].
Não inclua texto adicional.
```

## Conclusão

Few-Shot Learning é uma técnica poderosa que transforma a forma como interagimos com modelos de IA. Ao combinar **clareza nas instruções**, **exemplos representativos** e **formatos estruturados**, você cria prompts que produzem resultados consistentes e de alta qualidade. Na próxima vez que não estiver satisfeito com a resposta de uma IA, tente aplicar essas técnicas progressivamente. Você pode se surpreender com a melhora na qualidade!

**Experimente você mesmo:** Pegue uma tarefa que você frequentemente faz com IA e aplique as técnicas progressivamente:
1. Escreva o prompt básico
2. Adicione clareza e detalhes
3. Inclua 2-3 exemplos
4. Estruture a saída em JSON

Compare os resultados em cada etapa e veja a evolução!
