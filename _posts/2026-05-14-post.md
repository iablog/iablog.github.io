O `CodeAgent` dela é um CodeAct pronto para uso, e vamos explorá-lo analisando dados reais de dois dos políticos mais relevantes e pré-candidatos a governador(a) de Pernambuco, **João Campos** e **Raquel Lyra**, com acesso à API do YouTube para coleta dos dados.

## O que o smolagents entrega além do loop básico

**Autocorreção com traceback completo.** Se o código gerado lançar uma exceção, o agente recebe o traceback formatado como observação e pode se corrigir no turno seguinte.

**Ferramentas externas integradas.** Com `add_base_tools=True`, o agente ganha acesso a um buscador web sem nenhuma configuração extra. Com `tools=[sua_funcao]`, você pode adicionar qualquer ferramenta customizada usando o decorator `@tool`. O agente decide quando usar cada uma.

**Compatibilidade com qualquer modelo via LiteLLM.** Não há dependência de *function calling* nativo. Você pode usar Gemini, GPT, Claude ou modelos locais via Transformers, o `CodeAgent` funciona da mesma forma com todos.

**Controle de imports por segurança.** O agente só pode importar bibliotecas que você autorizar explicitamente em `additional_authorized_imports`. Isso não é uma limitação acidental, mas um controle deliberado que impede o agente de usar bibliotecas inesperadas.

## Configuração

### Instalação

O primeiro passo é instalar a biblioteca `smolagents` com suporte ao LiteLLM, que é o que permite usar diferentes modelos de linguagem de forma unificada.

### Imports

Com a biblioteca instalada, importamos os componentes principais que vamos utilizar ao longo do artigo.

```python

from smolagents import CodeAgent, LiteLLMModel
from google.colab import userdata
```

### Criando o acesso ao modelo

Aqui instanciamos o modelo de linguagem que o agente vai usar. Antes de executar esta célula, você precisa ter a chave de API configurada, veja como fazer isso no nosso [Utilizando a API do Google Gemini](https://iablog.github.io/deep%20learning/2025/07/06/post.html).

```python

model = LiteLLMModel(
    model_id="gemini/gemini-2.5-flash",
    api_key=userdata.get("GOOGLE_API_KEY"),
    timeout=60  # máximo 60s por chamada ao modelo
)
```

O mesmo código funcionaria com `anthropic/claude-4-7-opus`, `openai/gpt-5.4` ou qualquer modelo suportado pelo LiteLLM, basta trocar o `model_id` e a chave de API correspondente.

### Instanciando o Agente

Antes de iniciar as análises, criamos o `CodeAgent` com as configurações que vamos usar. Os `additional_authorized_imports` definem quais bibliotecas Python o agente está autorizado a importar durante a execução do código gerado.

```python

agente = CodeAgent(
    tools=[],
    model=model,
    max_steps=5,  # máximo 5 iterações por tarefa
    additional_authorized_imports=[
        'pandas', 'numpy', 'matplotlib',
        'matplotlib.pyplot', 'seaborn', 'scipy', 're'
    ],
    verbosity_level=2  # mostra o que está acontecendo em tempo real
)

print("Agente criado com sucesso!")
```

## Os Dados

Coletamos os vídeos mais recentes dos canais de João Campos e Raquel Lyra via YouTube Data API v3. O dataset tem **92 vídeos no total**, 50 de João Campos e 42 de Raquel Lyra.

```python

import pandas as pd

DF = pd.read_csv('dados_youtube.csv')
DF['data'] = pd.to_datetime(DF['data'])
```

| Coluna | Descrição |
|---|---|
| `titulo` | Título do vídeo |
| `data` | Data e hora de publicação (UTC) |
| `visualizacoes` | Total de views |
| `curtidas` | Total de likes |
| `comentarios` | Total de comentários |
| `duracao` | Duração em formato ISO 8601 (ex: `PT1M37S`) |
| `perfil` | `joao_campos` ou `raquel_lyra` |

Note que a coluna `duracao` vem no formato ISO 8601 e o agente precisa lidar com essa conversão sozinho, sem nenhuma instrução de como fazer.

## Análise 1: Visão Geral Comparativa

A primeira tarefa é uma exploração geral dos dois perfis. Passamos o dataframe diretamente para o agente e pedimos a comparação em linguagem natural, sem especificar como calcular, só o que queremos saber.

```python

resposta1 = agente.run(
    "Analise esse dataset de vídeos do YouTube de dois políticos pernambucanos, "
    "João Campos e Raquel Lyra. Compare os dois perfis em termos de: volume de publicações, "
    "médias de visualizações e curtidas, e duração típica dos vídeos. "
    "A coluna 'duracao' está no formato ISO 8601 (ex: PT1M37S) — converta para segundos na análise. "
    "Apresente os resultados como texto corrido.",
    additional_args={'posts_df': DF}
)
print(resposta1)
```

Saída real:

```

- João Campos publicou 50 vídeos.
- Raquel Lyra publicou 42 vídeos.

Média de visualizações:
- João Campos obteve uma média de 7746.08 visualizações por vídeo.
- Raquel Lyra obteve uma média de 7082.38 visualizações por vídeo.

Média de curtidas:

- A duração média dos vídeos de João Campos é de 68.30 segundos.

## Análise 2: Correlação entre Visualizações e Curtidas

Agora pedimos um gráfico. O agente precisa calcular correlações e gerar uma imagem, tudo em sequência, sem nenhuma orquestração explícita. Note que no prompt pedimos explicitamente que o agente retorne **somente** o nome do arquivo contendo o plot, sem textos extras, sem caminhos completos, apenas o nome do arquivo.

```python

resposta2 = agente.run(

    "eixos na mesma escala. Adicione a linha de tendência em cada gráfico. "
    "Retorne somente o nome do arquivo contendo o plot.",
    additional_args={'posts_df': DF}

from IPython.display import Image

E, como último passo, note que o agente gera uma chamada a uma função especial chamada `final_answer()`, passando a saída final que será retornada (neste caso, o nome do arquivo). ## Análise 3: Autocorreção em Ação

Este é o caso que melhor ilustra o que o smolagents acrescenta ao CodeAct manual. Pedimos uma análise estatística com decisão metodológica, o agente precisa *escolher* o teste certo antes de executar.

```python

resposta3 = agente.run(
    "Faça um teste estatístico adequado para avaliar se as distribuições de "
    "visualizações de João Campos e Raquel Lyra são iguais ou diferentes (p=0.05). "
    "Escolha o teste correto em função das características das distribuições — "
    "verifique normalidade antes de decidir. "
    "Se forem diferentes, informe qual perfil tem média maior. "
    "Gere um relatório em Markdown com metodologia, teste escolhido e resultados. "
    "Gere também uma imagem das duas distribuições. "
    "Retorne como par: (texto_markdown, nome_arquivo_imagem).",
    additional_args={'posts_df': DF}
)

from IPython.display import Markdown, Image
Markdown(resposta3[0])
```

```python
Image(resposta3[1])
```

Na nossa execução, o agente se autocorrigiu em tempo real. No **Step 1**, tentou usar `scipy.stats` para o teste Shapiro-Wilk e recebeu este erro:

```
Code execution failed at line 'shapiro_joao_campos = stats.shapiro(joao_campos_views)'
due to: InterpreterError: Forbidden access to module: scipy.stats
```

No **Step 2**, leu o traceback, adaptou a estratégia e executou com `numpy` e `seaborn`, gerando um relatório descritivo com visualização. Veja o relatório produzido:

> **Relatório de Comparação de Visualizações: João Campos vs. Raquel Lyra**
>
> **Metodologia e Limitações**
>
> O módulo `scipy.stats` não pôde ser utilizado por restrição de imports. A análise foi limitada a estatísticas descritivas e visualização gráfica.
>
> **João Campos:** Média 7746.08 · Mediana 5325.50 · Desvio padrão 6434.87
>
> **Raquel Lyra:** Média 7082.38 · Mediana 6808.00 · Desvio padrão 5390.52
>
> O perfil com maior média de visualizações é **João Campos**. Sem um teste estatístico formal, não é possível afirmar com nível de significância p=0.05 se a diferença é estatisticamente significativa.

![Distribuição de visualizações por perfil](/assets/img/post_05_14/analise_3.png)

O comportamento aqui é direto: o erro virou observação e o agente ajustou o plano sem nenhuma intervenção. No CodeAct manual, esse ciclo exigiria um `try/except` explícito no loop principal. Aqui acontece automaticamente.

## Análise 4: Integrando Busca na Web

O `CodeAgent` aceita ferramentas externas. Com `add_base_tools=True`, o agente ganha acesso a um buscador web sem configuração adicional. Aqui criamos um segundo agente com essa opção habilitada para combinar informações da web com os dados do dataset.

```python

agente_web = CodeAgent(
    tools=[],
    model=model,
    add_base_tools=True
)

resposta4 = agente_web.run(
    "Pesquise na web quais são as principais pautas políticas de João Campos "
    "e Raquel Lyra em 2026. Com base nisso, os títulos dos vídeos coletados "
    "refletem essas pautas? Analise e traga exemplos dos títulos do dataset.",
    additional_args={'posts_df': DF}
)
print(resposta4)
```

O agente usou 6 passos para completar a tarefa: buscou na web em português e em inglês, se autocorrigiu quando o pandas não estava autorizado no `agente_web` e adaptou para trabalhar com os dados como lista de dicionários. A resposta final:

```
As pautas políticas de João Campos para 2026 incluem investimentos em
infraestrutura (saúde, educação, urbanismo), moradia e resposta a desastres
naturais. Os títulos dos seus vídeos refletem fortemente estas pautas:
  - Infraestrutura: 'Hospital de Amor de Garanhuns', 'Parque Eduardo Campos',
    'Hospital da Criança do Recife'
  - Resposta a chuvas: 'chuvas no Recife', 'alerta máximo por conta do alto
    volume de chuvas'

Para Raquel Lyra, as pautas abrangem socorro a desastres, desenvolvimento
econômico, infraestrutura e políticas de saúde, educação e meio ambiente.
Os títulos dos seus vídeos refletem estas pautas com exemplos como:
  - Saúde/social: 'Gravidez NÃO é problema!', 'Meu primeiro boletim escolar'
  - Infraestrutura: 'BR-104 em duplicação', 'Com a gente, obra começa e termina'
```

Este é um exemplo de agente que combina duas fontes de informação, web e dataset local, sem nenhuma orquestração explícita. O agente decide quando buscar na web e quando analisar os dados.

## Múltiplos Turnos com Memória

Por padrão, cada `agente.run()` começa do zero. Para conversas de múltiplos turnos, use `reset=False`:

```python

r1 = agente.run(
    "Qual o vídeo com mais visualizações de cada perfil?",
    additional_args={'posts_df': DF}
)
print(r1)
```

```
João Campos: "Sextou com trabalho! Vistoriando a limpeza do Canal do Arruda"
             → 32.777 visualizações

Raquel Lyra: "Com a gente, obra começa e termina! BR-104 em duplicação!"
             → 22.290 visualizações
```

```python

r2 = agente.run(
    "E qual a diferença percentual de views entre eles?",
    reset=False  # mantém o histórico do turno anterior
)
print(r2)
```

```
A diferença percentual de views entre o vídeo mais visto de João Campos
e o de Raquel Lyra é de aproximadamente 47.05%.
```

Sem `reset=False`, a segunda pergunta chegaria ao agente sem contexto, ele não saberia quais vídeos estávamos comparando.

## Conclusão

O `CodeAgent` da smolagents é um CodeAct com a infraestrutura já pronta. O loop de execução, a captura de stdout, a autocorreção via traceback e o controle de imports. Tudo isso já vem implementado e testado.

O CodeAgent é especialmente útil para fazer uma análise exploratória de dados de forma simples e rápida, usando linguagem natural. É exatamente o que fizemos aqui com os dados dos canais de João Campos e Raquel Lyra: passamos perguntas em português, e o agente gerou o código, executou, se autocorrigiu quando necessário e devolveu os resultados, sem que precisássemos escrever uma linha de infraestrutura.
